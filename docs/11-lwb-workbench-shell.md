# 11 LWB 工作台壳

> 历史设计/验收记录，包含当时的方案与限制，不作为当前使用指南。当前入口见[文档索引](README.md)和[快速开始](quickstart.md)。

> **状态（2026-08-31）**：产品导航只显示“对话”“场景能力包”和“设置”；已加载场景包可在该导航下增加自己的菜单。

## 可见模块

| 导航 | 界面 | 关键规则 |
|---|---|---|
| 对话 | 官方 Session 历史（工作区、置顶、搜索、归档）与官方 DSH Conversation | 会话、工作区与归档保持 DSH 原生边界；左栏即官方 `sidebar.workspaces` 浏览区，见[对话模块使用官方左栏](42-conversation-history-official.md) |
| 场景能力包 | 可搜索、筛选的市场卡片、详情抽屉与菜单注入 | 市场只检查 manifest；加载/卸载由 DSH Loader 在当前页面动态切换，保留市场内容并更新菜单 |
| 设置 | 工作台设置页，通过“系统设置”打开完整的 DSH 原生设置面板 | 服务商、模型、凭据、语言、主题、工具和审批由 DSH 管理 |

LWB 在 DSH `sidebar` slot 提供主导航，在 `shell.overlay` 提供管理页和“设置”页中的原生 settings seat。对话模块的左侧会话历史不是自绘的：LWB 声明 `sidebar.workspaces` 座位，由官方 `ui-workspace` 的 Workspace 浏览器填充。官方 DSH 仍控制 Session 创建、Conversation 渲染、详情、轨迹、模型、凭据、工具和权限。

## 设置入口

设置页使用“基础配置 → 系统设置 → 打开设置”，页面说明为“管理工作台的系统配置与偏好”。该入口复用 `sidebar.settings` 原生插槽，打开完整面板，涵盖通用设置、模型、插件、Agent 预设与已归档会话；它不是只进入模型页的快捷入口。DSH 的技术来源在“关于”中说明。

设置页按卡片分组，卡片之间保留 18px 间距，每张卡片有独立的标题区（标记、标题、说明）与内容区，避免此前“一张大卡片内堆叠分区”的层次问题：

| 卡片 | 内容 |
|---|---|
| 基础配置 | DSH 系统设置入口、DSH 账号登录/退出 |
| 场景任务默认模型 | 场景任务统一使用的模型选择；配音、字幕、封面服务仍各自配置 |
| LWB 账号 | 账号状态、登录/注册、会员与积分、购买套餐 |
| 关于 | 运行方式与工作台连接状态 |

LWB 账号卡片在登录表单/账号面板上方固定展示一条说明：不登录 LWB 账号也能使用工作台，LWB 账号主要用于加载部分场景能力包以及使用这些能力包对应的语音服务和图片服务。登录因此始终是可选项，不是启动前置条件；相关边界见 [LWB 账号、模型档位与场景服务](40-lwb-account-model-and-media-services.md)。

普通对话和能力包内部会话的模型配置均由 DSH 管理，能力包新建内部会话时读取 DSH 默认模型及认证。TTS、ASR、封面生图等业务连接仍在对应业务页面配置。缺少默认模型时，提示用户前往“设置 → 系统设置 → 模型”。

## 存储与刷新

- 浏览器仅持久化当前页面、外观和语言相关偏好；市场目录由 host `lwbPacks/market` 提供，左侧只读取运行中的 `lwbPacks/list`。
- 对话列表、搜索、工作区和归档列表均使用 DSH 原生会话数据。
- 场景能力包的 host/client 入口、菜单和数据模型均由包自身拥有；核心壳只负责目录与页面插槽。首个口播视频包的阶段工件留在当前 DSH 会话工作区。
